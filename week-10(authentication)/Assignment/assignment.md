# Assignment: Google Calendar Mini‑Scheduler

Build a small web app that uses OAuth 2.0 to let each user:

- Sign in with Google
  - Implement the Authorization Code flow to obtain an access token for the Calendar API.

- View upcoming events
  - After login, display the user’s next 5 events from their primary Google Calendar.

- Create a new event
  - Provide a simple form (title, date & time, optional “add Meet link”) and let the user add that event to their calendar.

## Tech stack

Use any language or framework you like (e.g. Node.js, Python, Java). Front‑end can be plain HTML/CSS/JS or minimal React.
